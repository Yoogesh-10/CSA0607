# CO4 Assignment 4B – Submission Package

**Language:** Python 3 (standard library)

## Structure
- `Task_1` through `Task_6`: independent task folders containing:
  - `src/`: implementation source
  - `tests/`: test cases and boundary/adversarial descriptions
  - `outputs/`: captured execution output and terminal-style screenshots
  - `README.md`: run instructions
- `Report/CO4_Assignment_4B_Report.docx`: assessment-style report with problem analysis, algorithms, results, test evidence and engineering discussion.

## Run each task
From the repository root:
```bash
python Task_1/src/task1.py
python Task_2/src/task2.py
python Task_3/src/task3.py
python Task_4/src/task4.py
python Task_5/src/task5.py
python Task_6/src/task6.py
```

All code uses the Python standard library. Please review the negative-edge test in Task 3 and adapt/expand its graph if your instructor expects a particular Dijkstra failure demonstration.
